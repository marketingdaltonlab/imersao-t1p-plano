# Imersão T1P · Plano de ação

Painel interno de acompanhamento da virada da Imersão T1P pra online (15/09/2026): countdown da abertura, checklist do dia a dia, decisões dos sócios e mecânica de venda.

A página publicada (`index.html`) é cifrada com StatiCrypt e abre só com senha. O HTML original fica em `source/` (fora do repositório).

Pra atualizar: substitua `source/index.html` pela versão nova e rode `./publicar.sh` (pede a senha e faz commit + push).
